# TaskFlow interface
A focused local task workspace: project navigation on the left, task list in the main area, native dialogs for creation and edits.

Palette: slate navigation #233750, ink #26364b, muted text #6d7888, blue action #365dc5, paper #f6f8fb, white surfaces #ffffff. Status colors convey work state; no decorative gradients.
Typography: Segoe UI/system sans, compact readable body, strong project heading. No external font download is required.
Layout: left-aligned project rail → project heading and owner → filters → task rows → pagination. On mobile the rail becomes a horizontal project selector, and rows stack status below the title.
Principles: prioritize real tasks over dashboard statistics; provide actionable empty states; preserve visible keyboard focus, native dialog focus handling, explicit destructive confirmation, and reduced motion.
